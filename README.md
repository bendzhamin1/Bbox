# Bbox

Буфер обмена для macOS. Живёт в строке меню, помнит скопированное, вызов по Option+V.

## Скачать

Возьмите Bbox-macOS.zip на странице [Releases](https://github.com/bendzhamin1/Bbox/releases).
Распакуйте двойным кликом и запустите Bbox.app. При первом запуске нажмите на приложение
правой кнопкой и выберите «Открыть».

## Клавиши

* Option+V — показать буфер
* Tab — листать вниз
* Enter — вставить
* Cmd+1..9 — вставить запись по номеру
* Esc — закрыть
