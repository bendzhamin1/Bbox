# Bbox

Менеджер буфера обмена для macOS. Живёт в строке меню, хранит историю
скопированного и по горячей клавише показывает её в маленьком окне у выбранного угла экрана.

Поставил и забыл. Настроек нет, окон нет, автозапуск при входе в систему.

## Что умеет

* Хранит историю буфера: текст и картинки.
* Вызов по Option+V.
* Поиск по тексту.
* Закрепление нужных записей, чтобы не терялись при очистке.
* Клавиатура: Tab листает вниз, Enter вставляет, Esc закрывает, Cmd+1..9 вставляют запись по номеру.
* Иконка в строке меню: левый клик открывает окно, правый даёт меню с выходом.
* Окно появляется слева снизу, а если его передвинуть, запоминает место и открывается там же после перезапуска.
* Данные лежат только на вашем компьютере, в сеть ничего не уходит.

## Требования

macOS 14 или новее. Нужны Command Line Tools (`xcode-select --install`).
Полный Xcode не требуется, сборка идёт через Swift Package Manager.

## Установка

```bash
git clone <repo-url>
cd Bbox
./scripts/install.sh
```

Скрипт соберёт приложение, положит его в /Applications, включит автозапуск и запустит.

При первом запуске macOS попросит доступ к разделу «Универсальный доступ»
(Accessibility). Он нужен, чтобы Bbox сам нажимал Cmd+V в активном приложении.
Без этого доступа выбранная запись просто кладётся в буфер, и вы вставляете её сами.

## Только собрать, без установки

```bash
./scripts/build_app.sh
```

Готовый бандл будет в build/Bbox.app.

Для разработки: `swift build` и `swift run`.

## Как пользоваться

1. Копируйте как обычно, Cmd+C.
2. Нажмите Option+V, откроется окно со списком.
3. Печатайте для поиска, листайте Tab или стрелками, вставляйте Enter или Cmd+1..9.

## Структура

| Файл | Что делает |
|------|-----------|
| App.swift | Точка входа. |
| AppDelegate.swift | Иконка в строке меню, горячая клавиша, автозапуск, защита от второго запуска. |
| ClipboardMonitor.swift | Следит за буфером и ловит новые записи. |
| HistoryStore.swift | История и её хранение в JSON. |
| ClipItem.swift | Одна запись. |
| Paster.swift | Кладёт запись в буфер и нажимает Cmd+V. |
| HotKey.swift | Глобальная горячая клавиша. |
| PanelController.swift | Плавающее окно, позиция и её запоминание. |
| Views/HistoryView.swift | Список, поиск, подсказки. |
| Views/RowView.swift | Карточка записи. |
